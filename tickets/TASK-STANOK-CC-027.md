# TASK-STANOK-CC-027 — stats: статистика по числам (smoke-тикeт)

## Контекст

Тестовый (smoke) тикет для проверки конвейера станка. Создаёт НОВЫЙ модуль
`src/stats.js` с чистыми функциями над массивами чисел. Не связан с игровым кодом;
НЕ трогать существующие модули (`src/vec2.js`, `src/vec3.js`, `src/vecops.js`,
`src/clamp.js`, `src/lerp.js`, `src/clamp01.js`, `src/dist.js`, `src/mat.js`,
`src/tetris/*` и все их тесты — не менять).

Цель прогона: одна чистая попытка (CLEAN-FIRST), без ретраев. Тикет намеренно
простой и самодостаточный.

## Требования

Модуль `src/stats.js` (CommonJS, `module.exports`) экспортирует:

1. `sum(a)` — сумма элементов массива чисел. Пустой массив → `0`.
2. `mean(a)` — среднее арифметическое: `sum(a) / a.length`. Пустой массив →
   `RangeError` с сообщением `"empty array"`.
3. `median(a)` — медиана: для нечётной длины — средний элемент отсортированного
   (по возрастанию) массива; для чётной — среднее двух средних. Пустой массив →
   `RangeError` с сообщением `"empty array"`. Функция НЕ мутирует входной массив.
4. `variance(a)` — дисперсия (популяционная):
   `sum((x - mean)^2) / a.length`. Меньше 2 элементов → `RangeError`
   с сообщением `"need >= 2"`.

Валидация аргументов (для всех функций):
- аргумент — массив; не-массив — `TypeError` с именем `"a"`.
- каждый элемент — конечное число; нечисло/`NaN`/`Infinity` — `TypeError`
  с индексом элемента в сообщении (например `"a[3]"`).

## Инварианты

- `sum([1,2,3])` → `6`; `sum([])` → `0`.
- `mean([1,2,3,4])` → `2.5`.
- `median([3,1,2])` → `2`; `median([4,1,3,2])` → `2.5`.
- `variance([2,4,4,4,5,5,7,9])` → `4` (сравнение через eps 1e-9).
- Все функции чистые и детерминированные: без `process`, `Date`, side effects;
  входные массивы не мутируются.

## Критерии приёмки

1. TDD: тест ПЕРВЫМ, красная фаза (модуль отсутствует → FAIL), затем зелёная.
2. `tests/stats.test.js` покрывает: базовые случаи всех четырёх функций,
   пустой массив → `RangeError` (для `mean`/`median`), `variance` с 0 и 1
   элементом → `RangeError`, `TypeError` для не-массива и для не-числа/`NaN`
   (с индексом в сообщении), немутацию входа в `median`.
   Числовые сравнения дробных результатов — через `Math.abs(a-b) < 1e-9`,
   НЕ `deepStrictEqual` на «красивых» дробях.
3. Все тесты проходят: `node --test tests/stats.test.js`.
4. `docs/stats.md` — краткая документация (сигнатуры, примеры, семантика ошибок).
