# TASK-STANOK-CC-016 — mat: матричные операции 2x2 (smoke-тикeт)

## Контекст

Тестовый (smoke) тикет для проверки конвейера станка. Создаёт новый модуль
`src/mat.js` с чистыми функциями над матрицами 2x2. Не связан с игровым кодом;
не трогает существующие модули (`src/utils.js`, `src/utils2.js`, `src/vec2.js`,
`src/vec3.js`, `src/angle.js`, `src/lerp.js`, `src/clamp.js`, `src/dist.js`
и их тесты не менять).

## Требования

Матрица 2x2 — объект `{a, b, c, d}` (строки: `[a, b]`, `[c, d]`):

```
[ a  b ]
[ c  d ]
```

Модуль `src/mat.js` (CommonJS, `module.exports`) экспортирует:

1. `identity()` — единичная матрица: `{a: 1, b: 0, c: 0, d: 1}`.
2. `mul(m, n)` — произведение двух матриц 2x2:
   - `a = m.a * n.a + m.b * n.c`
   - `b = m.a * n.b + m.b * n.d`
   - `c = m.c * n.a + m.d * n.c`
   - `d = m.c * n.b + m.d * n.d`
3. `mulVec(m, v)` — умножение матрицы на 2D-вектор `{x, y}`:
   `{x: m.a * v.x + m.b * v.y, y: m.c * v.x + m.d * v.y}`.
4. `det(m)` — определитель: `m.a * m.d - m.b * m.c`.
5. `transpose(m)` — транспонирование: `{a: m.a, b: m.c, c: m.b, d: m.d}`.

Валидация аргументов:
- матрица — объект с числовыми `a`, `b`, `c`, `d`; нечисловая компонента —
  `TypeError` с именем компоненты в сообщении (`"a"` / `"b"` / `"c"` / `"d"`);
- вектор — объект с числовыми `x`, `y`; нечисловая компонента — `TypeError`
  с именем компоненты (`"x"` / `"y"`).

## Инварианты

- `identity()` → `{a: 1, b: 0, c: 0, d: 1}`.
- `mul(identity(), m)` → `m` (для любой матрицы).
- `mulVec(identity(), {x: 3, y: 4})` → `{x: 3, y: 4}`.
- `det({a: 1, b: 2, c: 3, d: 4})` → `-2`.
- `transpose({a: 1, b: 2, c: 3, d: 4})` → `{a: 1, b: 3, c: 2, d: 4}`.
- `mul({a: 1, b: 2, c: 3, d: 4}, {a: 5, b: 6, c: 7, d: 8})` →
  `{a: 19, b: 22, c: 43, d: 50}`.
- Все функции чистые и детерминированные: без `process`, `Date`, side effects.
