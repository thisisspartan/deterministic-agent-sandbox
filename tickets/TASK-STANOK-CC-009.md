# TASK-STANOK-CC-009 — utils: форматирование координат игрока (smoke-тикeт)

## Контекст

Тестовый (smoke) тикет для проверки конвейера станка. Создаёт новый модуль
`src/utils.js` с одной чистой функцией. Не связан с игровым кодом; не трогает
существующие модули.

## Требования

1. `src/utils.js` экспортирует функцию `formatPos(x, y)`:
   - аргументы — числа (координаты игрока);
   - возвращает строку вида `"x=12.34 y=5.67"` — каждое значение округлено
     **вниз до 2 знаков** через `Math.floor(v * 100) / 100`, затем приведено
     к строке через `String()` (без доп. форматирования);
   - отрицательные значения — корректно (округление вниз, т.е. в сторону
     минус бесконечности: `Math.floor(-1.005 * 100) / 100 === -1.01`);
   - нечисловой аргумент (не `number` или `NaN`) — бросает `TypeError`
     с сообщением, содержащим имя аргумента (`"x"` или `"y"`).
2. Модуль — чистый: без `process`, `Date`, side effects; только `module.exports`.

## Инварианты

- `formatPos(0, 0)` → `"x=0 y=0"`.
- Функция детерминирована и чиста: одинаковый вход → одинаковая строка.

## Критерии приёмки

1. TDD: тест ПЕРВЫМ, красная фаза (модуль отсутствует → FAIL), затем зелёная.
2. `tests/utils.test.js` покрывает: базовый случай, округление до 2 знаков,
   отрицательные значения, `TypeError` для `NaN`/не-числа (для `x` и `y`).
3. Все тесты проходят: `node --test tests/` (или как запускает verifier).
4. `docs/utils.md` — краткая документация (сигнатура, примеры, семантика округления).

## Границы

- Не менять другие файлы `src/`, `tests/`, `docs/`.
- Никаких внешних зависимостей.
