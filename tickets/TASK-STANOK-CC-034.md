# TASK-STANOK-CC-034 — fire: видимое пламя без 256-цветов (глифы плотности)

## Контекст

Модуль `src/fire/` (тикеты 030–033): физика живая, пламя высокое, камин тёмный,
тесты зелёные. НО в реальном терминале оператора **огня не видно**:

- Ячейки пламени рендерятся как **цветные ПРОБЕЛЫ** (только ANSI-код `38;5;NNN`,
  глиф = `' '`). Терминал оператора НЕ применяет 256-цветные коды → пробелы
  остаются невидимыми.
- Кирпичи видны (у них глифы ▓ █ ▒), искры видны (✦), а само пламя — нет.
  Оператор видит пустое окно в стене + летящие ✦ и пишет «нет огня».

Диагноз подтверждён замером: в steady-state (seed=42, 30 step'ов) кадр содержит
цвета 160–221 (пламя) и 234 (фон окна), но у ячеек пламя-диапазона глиф — пробел.

Цель: пламя **видимо как форма в ЛЮБОМ терминале** — даже если тот игнорирует
256-цвета. Цвета остаются как бонус для терминалов, которые их поддерживают.

## Задача

### R1. Глифы плотности пламени (render, fire.js)
- Введи константу `FLAME_GLYPHS` — строка-рампа от редкого к плотному, например
  `" .:-=+*#%@"` (индекс 0 = пробел). Точный набор подбери сам, НО:
  - индекс 0 обязан быть пробелом (пусто);
  - глифы НЕ должны совпадать с кирпичными (▓ █ ▒) и не должны быть ✦ (искры);
  - последний (самый плотный) глиф — самый «тяжёлый» по визуальной массе.
- В `render()`: для ячейки окна (НЕ рамка) с `heat > FLAME_MIN` (порог ~0.08,
  подбери) ставь глиф из `FLAME_GLYPHS` по индексу `min(len-1, floor(heat * (len-1)))`.
  Ячейки с `heat <= FLAME_MIN` — пробел (фон окна, как сейчас).
- **Цвет кода (`38;5;NNN`) оставить как есть** — глиф и цвет идут вместе.
  Терминал с цветами покажет цветное пламя, без — покажет ASCII-форму.

### R2. Не сломать рамку и искры
- Кирпичи (рамка) — глифы ▓ █ ▒ + тёмная палитра {24,25,26,27,58}, без изменений.
- Искры ✦ — оверлей поверх ячейки, как сейчас (заменяют глиф ячейки).
- Тёмный фон окна (233–235) — сохранить.

### R3. Не ломать
- API: `createFire(opts)`, `render(state, width)`, `colorIndex`, `mulberry32` —
  сигнатуры не менять. `ui.js`, `main.js` — не трогать.
- Физика (step, heat, sparks, decay, flicker) — не трогать. Только render.
- Non-TTY режим main.js (10 кадров) — работает.
