## Задача
Реализовать модуль `src/fire/palette.py` и тесты к нему `tests/palette_test.py`.
`scripts/run.sh` уже существует (py-стек, pytest, `pythonpath=src`) — используй его как есть.

## Требования
1. Функция `generate_fire_palette() -> list[tuple[int, int, int]]`:
   - Возвращает массив ровно из 256 RGB-кортежей `(r, g, b)`.
   - Индекс 0: строго `(0, 0, 0)` (холодный/фон).
   - Точки перегиба:
     - 0..32: Черный -> Темно-красный (0,0,0 -> 140,0,0)
     - 33..96: Темно-красный -> Ярко-оранжевый (140,0,0 -> 255,100,0)
     - 97..180: Ярко-оранжевый -> Золотисто-желтый (255,100,0 -> 255,220,50)
     - 181..240: Желтый -> Белый (255,220,50 -> 255,255,230)
     - 241..255: Белый -> Бело-голубые горячие искры (255,255,230 -> 220,240,255)
   - Плавная линейная интерполяция между узлами.
2. Поддержка альтернативной палитры: `generate_blue_fire_palette()` (синее пламя / газ).

## Gate / Проверка
`bash scripts/run.sh test tests/palette_test.py`
- Длина палитры = 256.
- Значения R, G, B лежат строго в диапазоне [0..255].
- Яркость монотонно возрастает от 0 к 240.
