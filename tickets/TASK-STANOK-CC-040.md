# TASK-STANOK-CC-040 — fire: убрать камин (кирпичную раму) вокруг пламени

## Контекст (текущее состояние)
В `src/fire/fire.js` функция `render(state, width)` рисует статичную кирпичную
раму-камин вокруг «окна», где горит пламя:
- `plinth` — 2 нижних ряда, `lintel` — 2 верхних ряда, `pillar` — 2 столбца
  слева и справа (функция `frame(y, x)`);
- ячейки рамы — кирпичные глифы `▓ █ ▒` (`BRICKS`) в тёмной палитре
  `24,25,26,27,58` (`BRICK_COLORS`, `brickAt()`);
- ячейки окна — тёмный фон `234` (`DARK_BG`) при heat ≤ 0 и глифы пламени
  (`FLAME_GLYPHS`) при heat > `FLAME_MIN`;
- искры (`state.sparks`) не рисуются на ячейках рамы (`if (!frame(sy, sx))`).

## Задача
Убрать камин: пламя горит на всей сетке W×H, кирпичной рамы нет.

Объём изменений минимальный: `render()` в `src/fire/fire.js`, тесты в
`tests/fire/`, `docs/fire.md`. Физика и UI-цикл не трогаются.

## План (по шагам, без отклонений)
1. `src/fire/fire.js`:
   a. Удалить константы `BRICKS`, `BRICK_COLORS` и функцию `brickAt()`
      (и любые упоминания `plinth`/`lintel`/`pillar` внутри `render`).
   b. В `render(state, width)`: убрать вычисление `frame(y, x)` и кирпичный
      проход; каждая ячейка `(y, x)` рисуется как «оконная»:
      heat ≤ 0 → глиф фона на `DARK_BG` (234); heat > `FLAME_MIN` →
      глиф пламени по `FLAME_GLYPHS`; иначе — пустая ячейка на `DARK_BG`.
   c. Искры: рисовать, если `!s.dead` и ячейка в пределах сетки (clamp
      по `width`, как сейчас). Условие `if (!frame(sy, sx))` убрать.
   d. `step()` — НИ ОДНОЙ строки не менять.
2. `tests/fire/`: заменить/добавить ассерты по пунктам «Требования» 3;
   тесты физики не трогать.
3. `docs/fire.md`: убрать текст про камин/раму/кирпичи, описать новый вид.
4. Прогнать ВСЕ 8 тестовых файлов + `node src/fire/main.js` (non-TTY).

## Требования
1. `src/fire/fire.js`, `render(state, width)`:
   - Рамы нет: никаких `plinth`/`lintel`/`pillar`, ни одного кирпичного глифа
     (`▓ █ ▒`) в кадре. Нерисующиеся константы (`BRICKS`, `BRICK_COLORS`,
     `brickAt`) удалить.
   - ВСЕ ячейки сетки — «оконные»: пламя и искры рисуются на всю W×H
     (с учётом clamp по `width`, как сейчас).
   - Пустые ячейки (heat ≤ 0) — сохранить тёмный фон `234` (`DARK_BG`).
   - Припаркованные (мёртвые) искры — `s.dead === true` — НЕ рисовать
     (ранее их скрывала рама; теперь они оказались бы видны на нижнем ряду).
2. Физика `step()` — БЕЗ ИЗМЕНЕНИЙ: нагрев, фазы BURN/DIE/EMBER/REKINDLE,
   позиции углей, поведение искр, детерминизм по seed — всё как есть.
3. `tests/fire/` — обновить тесты под новый контракт (TDD):
   - в кадре `render()` нет глифов `▓ █ ▒`;
   - угловые ячейки `(0,0)`, `(0,cols-1)`, `(H-1,0)`, `(H-1,cols-1)` — тёмный
     фон или глиф пламени (НЕ кирпич);
   - мёртвые искры не рисуются;
   - существующие тесты физики (fire, lifecycle, ember, liveness, glyphs, ui,
     diag) остаются зелёными без ослабления ассертов.
4. `docs/fire.md` — обновить: убрать упоминания камина/рамы/кирпичей,
   описать новый вид (пламя на тёмном фоне на всю сетку).

## Критерии приёмки
1. `node --test tests/fire/fire.test.js`, `ui.test.js`, `render.test.js`,
   `glyphs.test.js`, `ember.test.js`, `lifecycle.test.js`, `liveness.test.js`,
   `diag.test.js` — все зелёные.
2. Кадр `render()`: ни одного `▓`, `█`, `▒`; угловые ячейки — не кирпич.

4. `docs/fire.md` обновлён.
