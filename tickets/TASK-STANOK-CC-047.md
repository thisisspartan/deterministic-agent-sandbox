## Требования

### C1. `slugify(str, sep)` (`src/slug.js`)

- Экспортировать `slugify` (module.exports).
- `str` — строка; если не строка (null/undefined/число) — бросить `TypeError`.
- `sep` — опциональный разделитель, строка длиной 1, по умолчанию `'-'`.
- Алгоритм:
  1. Привести к нижнему регистру (`toLowerCase`).
  2. Заменить КАЖДЫЙ ПРОБЕЛ (пробел, \t, \n, \r) на `sep`.
  3. Удалить ВСЕ символы, кроме `[a-z0-9]` и `sep` (включая акценты/кириллицу —
     они удаляются, а не транслитерируются).
  4. Схлопнуть повторяющиеся `sep` в один.
  5. Обрезать `sep` в начале и в конце.
- Результат — строка; пустая/только-мусорная строка → `''`.
- Без внешних зависимостей.

### C2. Тесты (`tests/slug.test.js` — НОВЫЙ файл, обязателен)

Использовать `const { test } = require('node:test')` и `require('node:assert')`.
Тесты (все детерминированные):

1. `slugify('Hello World')` → `'hello-world'`.
2. `slugify('  Trim   Me  ')` → `'trim-me'`.
3. `slugify('a--b  c')` → `'a-b-c'` (хлопание повторов).
4. `slugify('Привет Мир')` → `''` (кириллица удаляется).
5. `slugify('Café au lait')` → `'caf-au-lait'` (акцент `é` удаляется).
6. `slugify('---')` → `''`; `slugify('')` → `''`; `slugify('!!!')` → `''`.
7. `slugify('a_b.c:d', '_')` → `'a_b_c_d'` (кастомный sep, `.` и `:` удаляются).
8. `slugify(null)` → `TypeError`; `slugify(42)` → `TypeError` (assert.throws).
9. `slugify('a b', 'x')` → `'axb'` (sep используется как разделитель пробелов).
10. `slugify('A1 B2')` → `'a1-b2'` (цифры сохраняются).
