# TASK-STANOK-CC-015 — dist: расстояния и длины дуг (smoke-тикeт)

## Контекст

Тестовый (smoke) тикет для проверки конвейера станка. Создаёт новый модуль
`src/dist.js` с чистыми функциями вычисления расстояний. Не связан с игровым
кодом; не трогает существующие модули (`src/utils.js`, `src/utils2.js`,
`src/vec2.js`, `src/vec3.js`, `src/angle.js`, `src/lerp.js`, `src/clamp.js`
и их тесты не менять).

## Требования

Модуль `src/dist.js` (CommonJS, `module.exports`) экспортирует:

1. `dist2d(a, b)` — евклидово расстояние между двумя 2D-точками
   `{x, y}`: `Math.hypot(b.x - a.x, b.y - a.y)`.
2. `dist3d(a, b)` — евклидово расстояние между двумя 3D-точками
   `{x, y, z}`: `Math.hypot(b.x - a.x, b.y - a.y, b.z - a.z)`.
3. `arcLength(r, theta)` — длина дуги окружности радиуса `r`
   при угле `theta` (радианы): `r * theta`.

Валидация аргументов:
- точка — объект с числовыми компонентами; нечисловая компонента — `TypeError`
  с именем компоненты в сообщении (`"x"` / `"y"` / `"z"`);
- `r` — число, `theta` — число; нечисловой — `TypeError`
  (имя `"r"` / `"theta"`);
- `r < 0` — `RangeError` с сообщением `"negative radius"`;
- `theta < 0` — `RangeError` с сообщением `"negative angle"`.

## Инварианты

- `dist2d({x: 0, y: 0}, {x: 3, y: 4})` → `5`.
- `dist2d({x: 1, y: 1}, {x: 1, y: 1})` → `0`.
- `dist3d({x: 0, y: 0, z: 0}, {x: 2, y: 3, z: 6})` → `7`.
- `arcLength(1, Math.PI)` → `Math.PI`.
- `arcLength(2, Math.PI / 2)` → `Math.PI`.
- Все функции чистые и детерминированные: без `process`, `Date`, side effects.

## Критерии приёмки

1. TDD: тест ПЕРВЫМ, красная фаза (модуль отсутствует → FAIL), затем зелёная.
2. `tests/dist.test.js` покрывает: базовые случаи всех трёх функций,
   `RangeError` для `r < 0` и `theta < 0`, `TypeError` для не-числа/`NaN`
   (для каждой компоненты каждой точки и для скаляров).
   Числовые сравнения дробных результатов — через
   `assert.ok(Math.abs(actual - expected) < 1e-9)`, НЕ `deepStrictEqual`.
3. Все тесты проходят: `node --test tests/`.
4. `docs/dist.md` — краткая документация (сигнатуры, примеры, семантика ошибок).

## Границы

- Не менять другие файлы `src/`, `tests/`, `docs/`.
- Никаких внешних зависимостей.
- При завершении: все тесты `node --test tests/*.test.js` зелёные, артефакты
