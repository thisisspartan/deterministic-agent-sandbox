## Требования

### C1. `mulberry32(seed)` (`src/rng.js`)

- Экспортировать `mulberry32` (module.exports).
- `seed` — любое целое; нормализовать к uint32 через `seed >>> 0`.
- Возвращает ФУНКЦИЮ `rng()` без аргументов.
- Каждый вызов `rng()` возвращает float в `[0, 1)` (т.е. `0 <= x < 1`).
- Детерминирован: один и тот же `seed` → идентичная последовательность.
- НЕ использовать `Math.random` (и любые другие источники энтропии).
- Алгоритм — стандартный mulberry32 (или любой корректный 32-битный PRNG),
  но ОБЯЗАТЕЛЬНО детерминированный и равномерный (не константа).

### C2. `randInt(rng, min, max)` (`src/rng.js`)

- `rng` — функция вида `() => [0,1)` (например, от `mulberry32`).
- `min`, `max` — целые, `min <= max`.
- Возвращает равномерное ЦЕЛОЕ число в `[min, max]` ВКЛЮЧИТЕЛЬНО.
- Результат — целое (`Number.isInteger(x) === true`).
- Если `min > max` — бросить `RangeError`.

### C3. `pick(rng, arr)` (`src/rng.js`)

- Возвращает равномерно случайный ЭЛЕМЕНТ массива `arr`.
- Результат — один из элементов `arr` (равен по `===` одному из них).
- Если `arr.length === 0` — бросить `RangeError`.

### C4. `shuffle(rng, arr)` (`src/rng.js`)

- Fisher-Yates in-place перемешивание.
- Возвращает ТОТ ЖЕ объект-массив (мутирует на месте), т.е. `shuffle(rng, a) === a`.
- Результат — перестановка: тот же мультимножество элементов (сортированная копия
  равна сортированной копии исходного).
- Детерминирован при заданном `rng` (тот же seed → тот же результат).
- Длины 0 и 1 — порядок не меняется.

### C5. Тесты (`tests/rng.test.js` — НОВЫЙ файл, обязателен)

Использовать `const { test } = require('node:test')` и `require('node:assert')`.
Тесты (все должны быть детерминированными, без `Math.random`):

1. `mulberry32(1)` возвращает функцию (`typeof === 'function'`).
2. Детерминизм: `mulberry32(12345)` и второй `mulberry32(12345)` дают идентичные
   первые 100 значений (поэлементно `===`).
3. Диапазон: 10000 вызовов `mulberry32(1)()` — все в `[0, 1)`.
4. Разброс: 10000 вызовов `mulberry32(1)()` — `min < 0.05` И `max > 0.95`
   (не константа, не вырождено).
5. Разные seed → разные последовательности: первые 100 значений `mulberry32(1)`
   и `mulberry32(2)` НЕ все равны (есть хотя бы одно различие).
6. `randInt(rng, 1, 6)` (rng = `mulberry32(42)`): 1000 вызовов — все целые в `[1,6]`;
   количество различных значений >= 4.
7. `randInt(rng, 5, 5)` → всегда `5` (100 вызовов).
8. `randInt(rng, 3, 1)` → бросает `RangeError` (assert.throws).
9. `pick(rng, ['a','b','c'])` (rng = `mulberry32(7)`): 1000 вызовов — каждый результат
   один из `['a','b','c']`; количество различных результатов >= 2.
10. `pick(rng, [])` → бросает `RangeError` (assert.throws).
11. `shuffle(rng, [1,2,3,4,5])` (rng = `mulberry32(99)`): возвращает тот же ref
    (`===`); сортированная копия результата равна `[1,2,3,4,5]`; детерминизм —
    два `mulberry32(99)` дают одинаковый перемешанный массив.
12. `shuffle(rng, [])` → `[]`; `shuffle(rng, [7])` → `[7]` (порядок/состав не меняются).
