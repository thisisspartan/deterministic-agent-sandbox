# TASK-STANOK-CC-036 — fire: видимые угли (фикс маппинга глифов плотности)

## Контекст

Модуль `src/fire/` (тикеты 030–035): живое пламя, тёмный камин, глифы плотности,
жизненный цикл BURN→DIE→EMBER→REKINDLE. НО фаза **EMBER невидима**:

- `flameGlyphIndex(heat)` в `fire.js`: `heat <= FLAME_MIN (0.08)` → 0 (пробел),
  иначе `floor(heat * (len-1))` где len=10 → `floor(heat * 9)`.
- heat 0.09–0.111 → `floor(0.99..1.0)=0` → **пробел**, хотя heat > FLAME_MIN.
  Разрыв: диапазон (FLAME_MIN, 1/9) рендерится пустым.
- Угли живут в heat ~0.05–0.11 (winMax в EMBER ≈ 0.108) → **весь EMBER-кадр —
  пустое окно**. Оператор видит: огонь горит → окно пустое → «чуть проигрывается
  и всё».
- Тесты 035 проверяли heat-сетку, не глифы — дефект не пойман.

Цель: любой heat > FLAME_MIN даёт **непробельный** глиф; угли видны как
мерцающие точки/тире; BURN не меняется визуально в верхней части диапазона.

## Задача

### G1. Маппинг без разрыва (fire.js)
Перепиши `flameGlyphIndex(heat)`:
- `heat <= FLAME_MIN` → 0 (пробел) — как есть.
- `heat ∈ (FLAME_MIN, 1]` → индекс ∈ **[1, len-1]**, монотонно по heat, без
  разрывов: `i = clamp(round((heat - FLAME_MIN) / (1 - FLAME_MIN) * (len - 1)), 1, len - 1)`.
  (Точная формула — на твоё усмотрение, НО: непрерывность на (FLAME_MIN, 1]
  обязательна, max heat → самый тяжёлый глиф.)
- `FLAME_GLYPHS`, `FLAME_MIN` — не менять (если поменяешь порог — зафиксировать
  в docs).

### G2. Детерминированный доступ к фазам (для тестов)
Экспортируй из `fire.js` константы цикла (BURN_STEPS, DIE_STEPS, EMBER_STEPS,
REKINDLE_STEPS — как они названы в реализации) ИЛИ добавь `state.phase`
(текущая фаза) — чтобы тест детерминированно дошёл до EMBER. Сигнатуры
`createFire/render/colorIndex/mulberry32` не менять (новые экспорты — ок).

### G3. Не ломать
- Рамка (кирпичи), искры, тёмный фон окна — как есть.
- Физика (step, heat, фазы, PRNG) — не трогать. Только маппинг глифов + экспорты.
- `ui.js`, `main.js` — не трогать.
- BURN-кадр: верх пламени (низкий heat) станет чуть плотнее — это нормально,
  фикс разрыва; ядро (heat≈1) — самый тяжёлый глиф, как было.
- Существующие тесты (fire/render/liveness/glyphs/lifecycle/ui) — не ломать.
