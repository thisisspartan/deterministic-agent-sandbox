# TASK-STANOK-CC-014 — clamp: ограничение значения диапазоном (smoke-тикeт)

## Контекст

Тестовый (smoke) тикет для проверки конвейера станка. Создаёт новый модуль
`src/clamp.js` с чистыми функциями ограничения значений диапазонами. Не связан
с игровым кодом; не трогает существующие модули (`src/utils.js`,
`src/utils2.js`, `src/vec2.js`, `src/vec3.js`, `src/angle.js`, `src/lerp.js`
и их тесты не менять).

## Требования

Модуль `src/clamp.js` (CommonJS, `module.exports`) экспортирует:

1. `clamp(v, min, max)` — ограничение числа диапазоном:
   - `v < min` → `min`;
   - `v > max` → `max`;
   - иначе → `v`.
2. `clamp01(v)` — частный случай: `clamp(v, 0, 1)`.
3. `clampVec(v, min, max)` — покомпонентное ограничение 2D-вектора
   `{x, y}`: `{x: clamp(v.x, min.x, max.x), y: clamp(v.y, min.y, max.y)}`.

Валидация аргументов:
- `v`, `min`, `max` — числа; нечисловой аргумент — `TypeError` с именем
  аргумента в сообщении (`"v"` / `"min"` / `"max"`);
- `min > max` — `RangeError` с сообщением `"min > max"`;
- `clampVec`: `v`, `min`, `max` — объекты с числовыми `x`, `y`;
  нечисловая компонента — `TypeError` с именем компоненты (`"x"` / `"y"`).

## Инварианты

- `clamp(5, 0, 10)` → `5`.
- `clamp(-3, 0, 10)` → `0`.
- `clamp(42, 0, 10)` → `10`.
- `clamp(0.5, 0, 1)` → `0.5`.
- `clamp01(-1)` → `0`.
- `clamp01(2)` → `1`.
- `clampVec({x: -1, y: 5}, {x: 0, y: 0}, {x: 1, y: 1})` → `{x: 0, y: 1}`.
- Все функции чистые и детерминированные: без `process`, `Date`, side effects.
