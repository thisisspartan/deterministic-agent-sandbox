# TASK-STANOK-CC-042 — fire3d: цвет пламени (сейчас невидимо на тёмном терминале)

## Контекст
Существующий модуль `src/fire3d/` (fire3d.js, ui.js, main.js) + `tests/fire3d/` + `docs/fire3d.md`.
БАГ: в `render()` (`src/fire3d/fire3d.js`) ВСЕ ячейки — и пустые, и с пламенем — выводятся
в одном цвете `BG_CODE` = `\x1b[38;5;234m` (тёмный фон). На тёмном терминале глифы пламени
невидимы → пользователь видит пустой экран. Механика (физика, вращение, UI) работает.

Референс — 2D-модуль `src/fire/fire.js` (читать, НЕ менять):
- `colorIndex(t)` (t = heat [0..1]): 0 → пустой (фон 234), затем палитра 256-цветов:
  160 (тёмно-красный) → 196 (красный) → 202/214 (оранжевый) → 226 (жёлтый) → 231 (белый).
- Пустые ячейки (heat ≤ 0) — цвет 234; ячейки с теплом — цвет по `colorIndex`, глиф плотности
  из `FLAME_GLYPHS` (как уже есть в fire3d).

## Требования
1. `src/fire3d/fire3d.js` — `render(state, width, angle)`:
   - ячейка с max-теплом > 0 получает цвет по тому же маппингу, что `colorIndex` в
     `src/fire/fire.js` (та же палитра 160/196/202/214/226/231, те же пороговые интервалы);
     heat ≤ 0 → 234;
   - глифы плотности (`FLAME_GLYPHS`) остаются как есть (по плотности тепла);
   - кадры: соседние ячейки одного цвета группировать в один run (один escape-код на run),
     как строки строятся в `src/fire/fire.js` (per-cell токены → слияние по цвету);
   - остальной контракт render не меняется: чистая функция, Y-вращение, max-тепло на ячейку,
     y=0 снизу, ширина = width.
2. `tests/fire3d/render.test.js` — ДОПОЛНИТЬ (не ослаблять существующие ассерты):
   - сцена с пламенем: кадр содержит цветовые коды палитры (196/202/214/226/231),
     а не только 234;
   - пустая сцена: только 234 (и пробелы);
   - монотонность: hotter ячейка → индекс цвета не меньше, чем у холоднее (по палитре);
   - existing тесты (angle 0 vs π/2, чистота функции, без ▓█▒) остаются зелёными.
3. `docs/fire3d.md` — описать палитру пламени (как в docs/fire.md для 2D).
4. НЕ менять: `src/fire/`, `tests/fire/`, `src/fire3d/ui.js`, `src/fire3d/main.js`
   (если баг не воспроизводится без их правки — не трогать).
5. Финальный прогон ОДНОЙ командой: `node --test tests/fire3d/ && node --test tests/fire/`.
