# TASK-STANOK-CC-017 — grid: сеточные операции (smoke-тикeт)

## Контекст

Тестовый (smoke) тикет для проверки конвейера станка. Создаёт новый модуль
`src/grid.js` с чистыми функциями над прямоугольными сетками (массивы строк).
Не связан с игровым кодом; не трогает существующие модули
(`src/utils.js`, `src/utils2.js`, `src/vec2.js`, `src/vec3.js`, `src/angle.js`,
`src/lerp.js`, `src/clamp.js`, `src/dist.js`, `src/mat.js` и их тесты не менять).

## Требования

Сетка — массив строк, каждая строка — массив ячеек; все строки одной длины.

Модуль `src/grid.js` (CommonJS, `module.exports`) экспортирует:

1. `create(rows, cols, value)` — сетка `rows x cols`, все ячейки = `value`.
   - `rows`, `cols` — целые числа > 0; иначе `RangeError`
     с сообщением `"invalid dimensions"`.
   - `value` — любое значение (без валидации).
2. `at(grid, r, c)` — значение ячейки `(r, c)` (0-based).
   - вне границ — `RangeError` с сообщением `"out of bounds"`.
3. `set(grid, r, c, value)` — присваивание значения ячейке `(r, c)`
   (мутация сетки), возвращает саму сетку.
   - вне границ — `RangeError` с сообщением `"out of bounds"`.
4. `width(grid)` — количество столбцов (длина первой строки).
5. `height(grid)` — количество строк.
6. `inBounds(grid, r, c)` — `true`, если `(r, c)` внутри сетки, иначе `false`.
   (без исключений).
7. `clone(grid)` — глубокое копирование сетки (новые строки, новые ячейки-объекты
   не требуются: копируются значения; если ячейка — объект, копируется ссылкой
   на тот же объект).

Валидация аргументов:
- `grid` — массив строк; не-массив — `TypeError` с именем `"grid"`;
- `r`, `c` — целые числа; нечисловые/дробные — `TypeError`
  с именем `"r"` / `"c"`;
- `rows`, `cols` — целые числа; нечисловые/дробные — `TypeError`
  с именем `"rows"` / `"cols"`.

## Инварианты

- `create(2, 3, 0)` → `[[0, 0, 0], [0, 0, 0]]`.
- `at(create(2, 3, 7), 1, 2)` → `7`.
- `width(create(2, 3, 0))` → `3`.
- `height(create(2, 3, 0))` → `2`.
- `inBounds(create(2, 3, 0), 1, 2)` → `true`.
- `inBounds(create(2, 3, 0), 2, 0)` → `false`.
- `clone` возвращает новую сетку: `clone(g) !== g`, `clone(g)[0] !== g[0]`,
  но `clone(g)[0][0] === g[0][0]` (значения совпадают).
- Все функции чистые, кроме `set` (мутация — по спецификации).
  Без `process`, `Date`, side effects.

## Критерии приёмки

1. TDD: тест ПЕРВЫМ, красная фаза (модуль отсутствует → FAIL), затем зелёная.

3. Все тесты проходят: `node --test tests/`.
4. `docs/grid.md` — краткая документация (сигнатуры, примеры, семантика ошибок).
