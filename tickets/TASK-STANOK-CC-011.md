# TASK-STANOK-CC-011 — angle: работа с углами в радианах (smoke-тикeт)

## Контекст

Тестовый (smoke) тикет для проверки конвейера станка. Создаёт новый модуль
`src/angle.js` с чистыми функциями над углами (радианы). Не связан с игровым
кодом; не трогает существующие модули (`src/utils.js`, `src/utils2.js`,
`src/vec2.js` и их тесты не менять).

## Требования

Модуль `src/angle.js` (CommonJS, `module.exports`) экспортирует:

1. `normalizeAngle(a)` — приведение угла к диапазону `(-PI, PI]`:
   - аргумент — число; нечисловой (не `number` или `NaN`) — `TypeError`
     с именем аргумента в сообщении (`"a"`);
   - результат: `r = a % (2*PI)`; если `r <= 0` — `r += 2*PI`; затем
     если `r > PI` — `r -= 2*PI`. Итог всегда в `(-PI, PI]`.
2. `angleDiff(a, b)` — минимальная направленная разница `b - a`,
   приведённая к `[-PI, PI]` через `normalizeAngle(b - a)`.
   - оба аргумента — числа; нечисловой — `TypeError`
     (имя аргумента: `"a"` / `"b"`).
3. `lerpAngle(a, b, t)` — интерполяция по кратчайшей дуге:
   `a + angleDiff(a, b) * t`, результат приведён через `normalizeAngle`.
   - `t` — число; нечисловой `t` — `TypeError` (имя `"t"`);
   - `t` вне `[0, 1]` — НЕ ошибка (экстраполяция допустима).

## Инварианты

- `normalizeAngle(3 * Math.PI)` → `Math.PI` (верхняя граница включена).
- `normalizeAngle(0)` → `0`.
- `angleDiff(0, Math.PI)` → `Math.PI`; `angleDiff(0, -Math.PI)` → `-Math.PI`.
- `lerpAngle(0, Math.PI, 0.5)` → `Math.PI / 2`.
- Все функции чистые и детерминированные: без `process`, `Date`, side effects.
