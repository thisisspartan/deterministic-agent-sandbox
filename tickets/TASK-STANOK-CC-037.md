# TASK-STANOK-CC-037 — fire: длинное горение (BURN ~3 мин)

## Контекст
Пользователь жалуется: огонь «не горит долго» — он должен гореть долго (минуты),
пока пользователь сам не остановит его (q/Q/ESC/Ctrl+C — уже работают в ui.js).
Сейчас фаза BURN длится 1500 шагов (~50 с при 30 FPS) — мало.

## Что сделать
Увеличить длительность фазы BURN до **5400 шагов (~3 мин при 30 FPS)**.
Остальные фазы жизненного цикла НЕ менять: DIE=360, EMBER=240, REKINDLE=240.
Новый полный цикл: 5400+360+240+240 = **6240 шагов**.

### Файлы
1. `src/fire/fire.js`
   - `BURN_STEPS = 1500` → `BURN_STEPS = 5400` (константа ~строка 61,
     комментарий «~50 s at 30 FPS» → «~3 min at 30 FPS»).
   - `BURN_STEPS` уже экспортируется в `module.exports` — экспорт не менять.
   - Ничего больше в физике/рендере НЕ трогать.
2. `tests/fire/lifecycle.test.js` (права на правку — у tester-субагента)
   - Зафиксированные в тесте константы расписания обновить под новые значения:
     `BURN_STEPS = 5400`, `CYCLE = 6240` (комментарии с секундами обновить).
   - Логика всех тестов L1–L6 остаётся прежней (они параметризованы этими
     константами). Проверить, что все индексы/срезы по-прежнему валидны при
     новом CYCLE.
   - ВАЖНО: тесты прогоняют полный цикл (CYCLE+300 шагов) и L5 — два цикла
     подряд. При 6240 шагов это ~13k вызовов step() — допустимо (чистая
     арифметика по сетке 80×24, < 1–2 с). Если node --test упрётся в timeout —
     это дефект, чинить производительностью step() НЕ надо; просто убедиться,
     что прогон проходит.
3. `tests/fire/ember.test.js` — `BURN_STEPS` импортируется из fire.js,
   менять НЕ надо (проверить, что тест зелёный без правок).
4. `docs/fire.md` — обновить описание жизненного цикла: длительность BURN
   ~3 мин (5400 шагов), полный цикл 6240 шагов.

## Критерии приёмки
- A1. В `src/fire/fire.js` `BURN_STEPS === 5400`; DIE/EMBER/REKINDLE не изменились
  (360/240/240).
- A2. `node --test tests/fire/lifecycle.test.js` — PASS (с обновлённым расписанием).
- A3. Все остальные `tests/fire/*.test.js` — PASS без изменений (кроме
  lifecycle.test.js).
- A4. `docs/fire.md` отражает новые длительности.
- A5. Smoke: `bash scripts/run.sh smoke src/fire/main.js` — не падает.

## Ограничения
- Писать только в `src/`, `tests/`, `docs/`.
- Не менять ui.js, main.js, render, глифы, палитру, физику пламени.
