## Требования

Модуль `src/vec3.js` (CommonJS, `module.exports`) экспортирует:

1. `add(a, b)` — покомпонентное сложение: `{x: a.x + b.x, y: a.y + b.y, z: a.z + b.z}`.
2. `sub(a, b)` — покомпонентное вычитание: `{x: a.x - b.x, y: a.y - b.y, z: a.z - b.z}`.
3. `scale(v, s)` — умножение на скаляр: `{x: v.x * s, y: v.y * s, z: v.z * s}`.
4. `dot(a, b)` — скалярное произведение: `a.x * b.x + a.y * b.y + a.z * b.z`.
5. `cross(a, b)` — векторное произведение:
   `{x: a.y * b.z - a.z * b.y, y: a.z * b.x - a.x * b.z, z: a.x * b.y - a.y * b.x}`.
6. `length(v)` — длина вектора: `Math.sqrt(v.x * v.x + v.y * v.y + v.z * v.z)`.
7. `normalize(v)` — приведение к единичной длине: `scale(v, 1 / length(v))`;
   нулевой вектор — `RangeError` с сообщением `"zero vector"`.

Валидация аргументов (для всех функций):
- вектор — объект с числовыми `x`, `y`, `z`; нечисловая компонента — `TypeError`
  с именем компоненты в сообщении (`"x"` / `"y"` / `"z"`);
- скаляр `s` — число; нечисловой — `TypeError` (имя `"s"`).

## Инварианты

- `add({x:1,y:2,z:3}, {x:4,y:5,z:6})` → `{x:5, y:7, z:9}`.
- `sub({x:5,y:7,z:9}, {x:1,y:2,z:3})` → `{x:4, y:5, z:6}`.
- `dot({x:1,y:0,z:0}, {x:0,y:1,z:0})` → `0`.
- `cross({x:1,y:0,z:0}, {x:0,y:1,z:0})` → `{x:0, y:0, z:1}`.
- `length({x:3, y:4, z:0})` → `5`.
- `normalize({x:0, y:0, z:5})` → `{x:0, y:0, z:1}`.
- Все функции чистые и детерминированные: без `process`, `Date`, side effects.
