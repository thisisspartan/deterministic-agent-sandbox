# TASK-STANOK-CC-043 — fire3d: чёрный экран (кадр стирается сам собой)

## Контекст
Модуль `src/fire3d/` работает, но в реальном терминале пользователь видит ВЕЧНО ЧЁРНЫЙ ЭКРАН.
КОРНЕВАЯ ПРИЧИНА (установлена супервайзером): в `src/fire3d/fire3d.js` константа
`CLEAR_TAIL = ESC + '[2J'` — это «стереть ВЕСЬ экран». Она стоит в КОНЦЕ каждого кадра
(`CURSOR_HOME + lines + '\n' + CLEAR_TAIL`), т.е. кадр рисуется и немедленно стирается.

Референс — 2D-модуль `src/fire/fire.js` (читать, НЕ менять), строка ~312:
`CLEAR_TAIL = ESC + '[' + 'J'` — это `\x1b[J` (стереть от курсора до конца экрана).
Там в конце кадра есть `'\n'` после последней строки, поэтому курсор оказывается НИЖЕ кадра
и `\x1b[J` счищает только хвост, а не сам кадр. 2D fire у пользователя отображается нормально.

## Требования
1. `src/fire3d/fire3d.js`: `CLEAR_TAIL = ESC + '[J'` (один символ: `2J` → `J`).
   Структура кадра остаётся: `CURSOR_HOME + lines.join('\n') + '\n' + CLEAR_TAIL`.
   Ничего больше в render() не менять (цвета, глифы, run-группировка, проекция).
2. `tests/fire3d/render.test.js` — ДОПОЛНИТЬ (не ослаблять существующие ассерты):
   - кадр НЕ содержит последовательность `\x1b[2J`;
   - кадр заканчивается `\x1b[J`;
   - глифы пламени (символы из FLAME_GLYPHS, кроме пробела) присутствуют в кадре
     ДО финальной очистки;
   - existing тесты остаются зелёными.
3. `docs/fire3d.md` — поправить описание структуры кадра (очистка `\x1b[J`, не `\x1b[2J`).
4. НЕ менять: `src/fire/`, `tests/fire/`, `src/fire3d/ui.js`, `src/fire3d/main.js`.
5. Финальный прогон ОДНОЙ командой: `node --test tests/fire3d/ && node --test tests/fire/`.

## Порядок работы (укладывайся в один ход)
1. Edit `src/fire3d/fire3d.js`: одна строка `CLEAR_TAIL`.
2. Edit `tests/fire3d/render.test.js`: новые кейсы.
3. Edit `docs/fire3d.md`.
