# TASK-STANOK-CC-010 — vec2: базовые векторные операции (smoke-тикeт)

## Контекст

Тестовый (smoke) тикет для проверки конвейера станка. Создаёт новый модуль
`src/vec2.js` с чистыми функциями 2D-векторной алгебры. Не связан с игровым
кодом; не трогает существующие модули (`src/utils.js`, `src/utils2.js` и их
тесты не менять).

## Требования

Модуль `src/vec2.js` (CommonJS, `module.exports`) экспортирует:

1. `length(x, y)` — длина вектора: `Math.hypot(x, y)`.
   - аргументы — числа; нечисловой аргумент (не `number` или `NaN`) —
     бросает `TypeError` с именем аргумента в сообщении (`"x"` / `"y"`).
2. `normalize(x, y)` — нормализованный вектор: возвращает объект
   `{ x: x / L, y: y / L }`, где `L = Math.hypot(x, y)`.
   - нулевой вектор `(0, 0)` — бросает `Error` с сообщением
     `"normalize: zero vector"`;
   - нечисловой аргумент — `TypeError` (как в `length`).
3. `add(a, b)` — покомпонентное сложение: `a` и `b` — объекты
   `{ x, y }` с числовыми полями; возвращает `{ x: a.x + b.x, y: a.y + b.y }`.
   - `a`/`b` не объект или поле не число/NaN — `TypeError`
     (сообщение содержит имя аргумента: `"a"` / `"b"`).

## Инварианты

- `length(3, 4)` → `5`.
- `normalize(3, 4)` → `{ x: 0.6, y: 0.8 }`.
- `add({ x: 1, y: 2 }, { x: 3, y: 4 })` → `{ x: 4, y: 6 }`.
- Все функции чистые и детерминированные: без `process`, `Date`, side effects.
