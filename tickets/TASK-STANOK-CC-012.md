# TASK-STANOK-CC-012 — lerp: линейная интерполяция и clamp (smoke-тикeт)

## Контекст

Тестовый (smoke) тикет для проверки конвейера станка. Создаёт новый модуль
`src/lerp.js` с чистыми функциями интерполяции. Не связан с игровым кодом;
не трогает существующие модули (`src/utils.js`, `src/utils2.js`, `src/vec2.js`
и их тесты не менять).

## Требования

Модуль `src/lerp.js` (CommonJS, `module.exports`) экспортирует:

1. `clamp(v, lo, hi)` — ограничивает `v` диапазоном `[lo, hi]`:
   - все аргументы — числа; нечисловой (не `number` или `NaN`) — `TypeError`
     с именем аргумента в сообщении (`"v"` / `"lo"` / `"hi"`);
   - `lo > hi` — `RangeError` с сообщением `"lo > hi"`.
2. `lerp(a, b, t)` — `a + (b - a) * t`:
   - все аргументы — числа; нечисловой — `TypeError`
     (имя аргумента: `"a"` / `"b"` / `"t"`);
   - `t` вне `[0, 1]` — НЕ ошибка (экстраполяция допустима).
3. `invLerp(a, b, v)` — обратная интерполяция: `(v - a) / (b - a)`:
   - все аргументы — числа; нечисловой — `TypeError`;
   - `a === b` — `RangeError` с сообщением `"a === b"` (деление на ноль).

## Инварианты

- `clamp(5, 0, 1)` → `1`; `clamp(-1, 0, 1)` → `0`; `clamp(0.5, 0, 1)` → `0.5`.
- `lerp(0, 10, 0.5)` → `5`; `lerp(10, 0, 0.5)` → `5`.
- `invLerp(0, 10, 5)` → `0.5`; `invLerp(0, 10, 10)` → `1`.
- Все функции чистые и детерминированные: без `process`, `Date`, side effects.
