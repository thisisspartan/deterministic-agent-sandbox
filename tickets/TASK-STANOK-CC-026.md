# TASK-STANOK-CC-026 — vecops: векторные утилиты (smoke-тикeт)

## Контекст

Тестовый (smoke) тикет для проверки конвейера станка. Создаёт НОВЫЙ модуль
`src/vecops.js` с чистыми функциями над 2D-векторами. Не связан с игровым кодом;
НЕ трогать существующие модули (`src/vec2.js`, `src/vec3.js`, `src/clamp.js`,
`src/lerp.js`, `src/clamp01.js`, `src/dist.js`, `src/mat.js`, `src/tetris/*`
и все их тесты — не менять).

Цель прогона: одна чистая попытка (CLEAN-FIRST), без ретраев. Тикет намеренно
простой и самодостаточный.

## Требования

Модуль `src/vecops.js` (CommonJS, `module.exports`) экспортирует:

1. `dist(a, b)` — евклидово расстояние между 2D-векторами:
   `Math.hypot(a.x - b.x, a.y - b.y)`.
2. `mid(a, b)` — середина отрезка: `{x: (a.x + b.x) / 2, y: (a.y + b.y) / 2}`.
3. `normalize2(v)` — приведение 2D-вектора к единичной длине:
   `{x: v.x / len, y: v.y / len}` где `len = Math.hypot(v.x, v.y)`;
   нулевой вектор — `RangeError` с сообщением `"zero vector"`.
4. `project(a, b)` — ортогональная проекция `a` на `b`:
   `scale(b, dot(a, b) / dot(b, b))` где `dot` — скалярное произведение;
   `dot(b, b) === 0` — `RangeError` с сообщением `"zero basis"`.

Валидация аргументов (для всех функций):
- вектор — объект с числовыми `x`, `y`; нечисловая компонента — `TypeError`
  с именем компоненты в сообщении (`"x"` / `"y"`).

## Инварианты

- `dist({x:0,y:0}, {x:3,y:4})` → `5`.
- `mid({x:0,y:0}, {x:2,y:4})` → `{x:1, y:2}`.
- `normalize2({x:3, y:4})` → `{x:0.6, y:0.8}` (сравнение через eps 1e-9).
- `project({x:1,y:1}, {x:1,y:0})` → `{x:1, y:0}`.
- Все функции чистые и детерминированные: без `process`, `Date`, side effects.
