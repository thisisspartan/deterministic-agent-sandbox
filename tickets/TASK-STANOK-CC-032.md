# TASK-STANOK-CC-032 — fire: рендер «камин» (рамка, тёмный фон, палитра)

## Контекст

Модуль `src/fire/` (тикет 030) + физика «камин» (тикет 031: центральный
источник, сужение кверху, полыхание, искры в центре). Тесты зелёные.

**Проблема:** пламя рендерится на светлом фоне терминала без обрамления —
не выглядит как камин. Нужна **рамка камина 2D БЕЗ брёвен** (оператор прямо
запретил брёвна/палки/символы дров).

## Задача: переделать рендер в `src/fire/` (render в fire.js)

### R1. Рамка камина
- Символы рамки: кирпич/камень — `▓`, `█`, `▒` в тёмных цветах палитры
  (24–27, 58, 236–239).
- Конструкция (только рамка, внутри пусто/тёмно):
  - **низ** — подиум: 1–2 ряда кирпичей по всей ширине окна;
  - **боковые стойки** — 1–2 колонки кирпичей слева и справа;
  - **перемычка/арка сверху** — 1–2 ряда (можно арку: углы выше, центр ниже
    или ровную перемычку — на выбор, но симметрично).
- Рамка **статична** (не мерцает, не зависит от heat).
- **Брёвен/палок/дров внутри камина НЕЛЬЗЯ.**

### R2. Тёмный фон внутри камина
- Окно камина (внутри рамки) — тёмный фон: ячейки с heat≈0 рендерятся
  тёмно-серым/чёрным (233–235) вместо «пустого» пространства, чтобы огонь
  горел «в темноте», а не на фоне терминала.
- Вне камина — как есть (пусто).

### R3. Палитра пламени
- Ядро — белое/жёлтое (226–231), середина — оранжевый (202–214),
  край — красный (196), тлеющий край — тёмно-красный (160).
- Если текущая палитра уже так — не менять; если нет — поправить STOPS.
- Искры — яркие пиксели поверх пламени (как есть).

### R4. Не ломать
- API `render(state, width) → string` — сохранить; можно добавить opts/
  внутренний хелпер `renderFireplace(...)`, но публичная сигнатура та же.
- `ui.js`, `main.js`, физика (step/heat/sparks) — НЕ менять.
- Детерминизм render: тот же state → тот же кадр.

## Тесты (TDD, `tests/fire/fire.test.js` или новый `tests/fire/render.test.js`)

1. **Рамка**: в отрендеренном кадре символы рамки присутствуют в углах/
   краях (низ, левая/правая стойка, верх), а в центре верхнего ряда окна —
   НЕ рамка. Проверка по символам/ANSI-кодам в строке кадра.
2. **Тёмный фон**: ячейка окна с heat=0 содержит ANSI-код тёмного цвета
   (233–235), а не просто пробел без цвета.
3. **Брёвен нет**: в кадре нет символов брёвен (например, `=`, `-`, `#`
   в нижней части окна) — явный отрицательный тест.
4. **Детерминизм render**: render(state) дважды → идентичные строки.
5. Существующие тесты — не ломать.

Запуск: `bash scripts/run.sh test tests/fire/fire.test.js`
(и `tests/fire/render.test.js`, если создашь; single-file).
