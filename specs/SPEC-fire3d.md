# SPEC-fire3d — объёмный (3D) огонь в консоли с вращением стрелками

## Цель
Отдельная консольная программа `fire3d`: объёмное пламя в 3D-объёме,
отрендеренное ASCII-глифами на тёмном фоне. Пользователь вращает сцену
стрелками ←/→ (вращение вокруг вертикальной оси); удержание стрелки даёт
плавное непрерывное вращение (за счёт автоповтора терминала). Выход —
`q` / `Q` / `ESC` / `Ctrl+C`.

Существующий 2D-модуль `src/fire/` НЕ трогается.

## Требования

### F1. Физика 3D-пламени (чистая логика, `src/fire3d/fire3d.js`)
- 3D-сетка `W×H×D` (дефолт 48×24×48, настраивается через opts), поле
  температуры `heat[y][x][z] ∈ [0..1]` (плоский Float32Array).
- Источник тепла — нижний слой `y=0`: базовая температура ~1.0 с фликером.
- Шаг симуляции (снизу вверх): `heat[y][x][z] = avg(heat[y-1][x±1..][z±1..]) * decay + noise*sparkle`,
  `decay ≈ 0.85..0.92`, clamp [0..1].
- Детерминизм: PRNG инжектируется (`opts.rng`, дефолт `mulberry32(seed)`).
  Один seed + одна последовательность `step()` → идентичные кадры.
- Горение вечное (без жизненного цикла).

### F2. Рендер 3D → 2D (ANSI)
- `render(state, width, angle) → string` (чистая функция): поворот voxels
  вокруг вертикальной оси на `angle` (радианы), проекция на экран
  (col из x', row из y), на каждую экранную ячейку — voxel с максимум heat.
- Глифы плотности (как `FLAME_GLYPHS` в fire), тёмный фон `234` при heat ≤ 0.
  Без кирпичей/рамы — пламя на всю сетку.
- `angle = 0` и `angle = π/2` дают РАЗНЫЕ кадры (вращение видно).

### F3. UI-цикл (`src/fire3d/ui.js`)
- `attach(io, fire, opts)` — паттерн как в `src/fire/ui.js`: raw mode,
  alt screen + cursor hide при старте, восстановление ВСЕГДА при stop.
- 30 FPS fixed-timestep loop (как в fire).
- Клавиши: одиночные `q`/`Q`/`ESC`/`Ctrl+C` → выход (как в fire, тикет 038).
  CSI-последовательности стрелок НЕ выходят:
  - `\x1b[D` (←) → угол уменьается на шаг (≈5°);
  - `\x1b[C` (→) → угол увеличивается на шаг (≈5°).
  Удержание стрелки = автоповтор CSI = плавное непрерывное вращение.

### F4. Entry point (`src/fire3d/main.js`)
- TTY → интерактивный режим.
- Non-TTY guard: отрендерить фиксированное число кадров (например 10) и
  `exit(0)`. Не вешается.

### F5. Гигиена
- Никаких внешних зависимостей; только `node:test`, `node:assert/strict`.
- Не трогать `src/fire/`, `src/tetris/` и остальные модули.
- `docs/fire3d.md`: запуск, управление (стрелки, клавиши выхода), параметры.

## Критерии приёмки
1. `node --test tests/fire3d/*.test.js` — все зелёные (физика: нагрев снизу
   вверх, 3D-распространение, детерминизм; рендер: поворот меняет кадр,
   пустая сцена — тёмный фон; ui: mock io, выход, стрелки меняют угол).
2. `node src/fire3d/main.js` в non-TTY: печатает кадры, exit 0, < 10 c.
3. Существующие `tests/fire/*` остаются зелёными без изменений.
4. Производительность: 100 кадров (step + render) < 2 c (тест).
5. `docs/fire3d.md` создан. Артефакты закоммичены.
