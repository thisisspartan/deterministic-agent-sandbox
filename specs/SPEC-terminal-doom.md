# SPEC-terminal-doom — консольная 3D-бродилка по лабиринту, в духе Doom

## Подтверждено оператором (грилл, 2026-08-23)

- Проект: консольная (терминальная) 3D-бродилка от первого лица по лабиринту, в духе Doom.
- Стек: Node.js.
- Геймплей: лабиринт + выход. Никаких врагов, предметов, HUD.
- Управление: W/S — вперёд/назад, A/D — поворот влево/вправо, Q/E — стрейф, стрелки — дубль WASD.
- Движение: real-time, game loop, зажатая клавиша = непрерывное движение/поворот.
- **Удержание = движение** (дополнение 2026-08-26, тикет 008): нажал клавишу — действие
  включено; отпустил — выключено. Терминал не шлёт keyup, поэтому «отпущено» определяется
  по прекращению автоповтора кода клавиши (повторы идут, пока клавиша зажата;
  прекратились — отпущена). Схему «удержание = движение» применяем ко ВСЕМ клавишам
  движения: W/S/A/D/Q/E и стрелки (стрелки дублируют WASD). Toggle-схема тикета 004
  (нажал — поехал, нажал ещё раз — остановился) отменяется. Esc — без изменений
  (sticky, выход из игры).
- Рендер: raycasting, ANSI-полублоки ▀▄ + градиент цвета по глубине.
- Экран: фиксированный 100x30 символов.
- Лабиринт: процедурная генерация, новый на каждом запуске, гарантированно проходим, ~25x25 клеток.
- Терминал меньше 100x30 → выход с сообщением.
- Победа: игрок достиг выхода → экран победы + выход из игры.

## Технические решения (следуют из подтверждённого; подтвердить при ревью спеки)

- Старт игрока — в одной из угловых клеток, выход — в противоположном углу.
- Выход визуально отмечен (стена/дверь другого цвета, видима, когда на неё смотришь).
- Коллизии: игрок не может пройти сквозь стены и не может выйти за границы карты.
- Esc — выход из игры (терминал возвращается в нормальный режим).
- Resize во время игры: если терминал стал меньше 100x30 — выход с тем же сообщением, что при старте.
- Game loop ~30 FPS; скорость движения и поворота — константы, подобраны под 100x30 и ~25x25.

## Failure-кейсы (что должно быть невозможным)

- Игрок проходит сквозь стену или оказывается за границей карты.
- Сгенерирован лабиринт, в котором выход недостижим.
- После выхода из игры (победа/Esc/ошибка) терминал остаётся в raw mode.
- Крах на любой клавише, на resize, на любом шаге game loop.

## Края

- Терминал ровно 100x30 → игра стартует.
- Терминал меньше 100x30 (при старте или при resize) → сообщение + выход.
- Игрок у границы карты → коллизия, выхода нет.
- Зажатая клавиша (повтор) → плавное непрерывное движение, не «рывки».
- Поворот на 360° и стрейф в стену → без артефактов рендера и без сдвига в стену.

## Acceptance criteria

1. Запуск в терминале ≥100x30: игра рендерит лабиринт от первого лица (raycasting, полублоки, градиент по глубине).
2. Управление работает как в разделе «Подтверждено»; коллизии со стенами и границей карты.
3. Достижение выхода → экран победы, процесс завершается с кодом 0, терминал восстановлен.
4. Esc → выход с кодом 0, терминал восстановлен.
5. Терминал <100x30 → сообщение, ненулевой код выхода.
6. Любой сгенерированный лабиринт проходим (проверка связностью start→exit, например BFS).
7. Рендер детерминирован: при заданных позиции/угле/карте framebuffer (100x30) стабилен (тестируемо без реального TTY).

## Границы «НЕ делать»

- Нет врагов, предметов, звуков, сети, сохранений, мыши, мультиплеера.
- Нет миникарты и HUD.
- Нет конфигурационных файлов и CLI-опций, кроме запуска.
- Не портировать на другие платформы/стеки.

## Предложенная нарезка на модули (для тикетов; не жёстко)

- `maze` — генерация лабиринта (процедурная, гарантированно проходимая) + проверка связности.
- `raycaster` — raycasting 100x30: framebuffer из полублоков + цвета по глубине (чистая функция: карта + позиция/угол → framebuffer).
- `player` — состояние игрока, движение, коллизии.
- `input` — raw mode, клавиши, Esc, восстановление терминала.
- `main` — game loop, склейка, экран победы, проверка размера терминала.

## Дополнение: тикет 006 (грилл 2026-08-25, подтверждено оператором)

- «Горизонтальные полосы» на стенах = швы между рядами глифа '█'
  (артефакт шрифта/терминала; НЕ содержимое framebuffer — цвет в столбце постоянен).
- Фикс: тело стены (полные строки, overlap >= 0.999) — '█' → '▓' (U+2593).
  Краевые строки '▄'/'▀' — без изменений.
- Цвет — без изменений (решение оператора): рампа по глубине и цвет выхода (46) не трогать.
