(`~/.claude/projects/-home-hermes-darkcast-stanok/*.jsonl`). Сервер тронут только

## TL;DR

Прогоны долгие НЕ из-за отсутствия Bash. Bash станку уже фактически выдан (10 вызовов
на прогон, гейт `run.sh` работает), но это не ускоряет: самые медленные прогоны — с Bash.
Узкие места — **объём думания** (CoT) и **последовательные субагенты** на один слот.
Docker с «полным bash» не лечит ни то, ни другое, а дополнительно теряет наши патчи 2.1.88
(B1 think_medium, компакшн) — образ ставит claude-code latest из npm. Рекомендация: docker НЕ
делать; ускоряться на рычагах думания/субагентов.

## Почему долго — 3 слоя

1. **Думание без границы (главный рычаг).** Шаблон `chat_template.jinja.new` (запущен!),
   строки 81–89: `reasoning_instructions` заданы ТОЛЬКО для `xhigh` и `low`.
   Для **`medium` — пусто** → модель не получает инструкции «кратко» и пишет длинные CoT
   (Edit-ходы дают гэпы 100–337s). При этом маркер B1 ставит на tool-ходы именно
   `medium`, а сервер kwargs `reasoning_effort=xhigh` форсит xhigh на первом ходе/субагентах.
   Связка «medium без инструкции + xhigh на субагентах» = раздутый CoT.
2. **Субагенты сериализуются.** `--parallel 1`, один слот. Обязательный reviewer
   (шаг 5 CLAUDE.md) + tester = полные вложенные сессии, каждая думает с xhigh-дефолтом.
   34–70% стены — это «рецензия» и «правка теста», а не работа по тикету.
3. **Сервер на пределе VRAM.** RTX 5060 Ti 16GB, конфиг перебирает бюджет ~1.8GB
   (fit abort, n_gpu_layers 99 форсом). Риск редких подвисаний (15-мин «hang» в 030).

## Оценка уже сделанных улучшений (целесообразность)

- **`run.sh`-писочница + bash-gate (e28c346, 26745bf) — целесообразно, работает.** Модель
  реально гоняет `bash scripts/run.sh test …` (10×/прогон), гейт пускает только whitelist-форму,
  `classify_criticality` авто-аллоуит SAFE-форму. Это уже «выдача Bash в безопасной форме».
  Дальше расширять whitelist точечно (по потребности тикета), не открывать всё.
- **Docker-подход (SPEC-docker-sandbox.md, Dockerfile, docker-run-claude.sh) — НЕ целесообразно
  в текущем виде.** (а) лечит не тот боттлнек: полный bash не сокращает думание/субагентов;
  (б) образ ставит `@anthropic-ai/claude-code` **latest из npm** — НЕ наш пропатченный 2.1.88,
  теряем B1 `<|think_medium|>` и патч компакшна (buffer 10000, секция 6) → думание снова
  неуправляемо и порог другой; (в) спека сама это признаёт: «метрика успеха ≤40 мин»,
  но docker не трогает зависания и качество модели. Держать как PLANNED нельзя без
  пересборки образа на патченный 2.1.88 — а это уже не «1 строка», это отдельный пайплайн.
- **Что докер реально даёт** (всё малый плюс): python/grep/sed в песочнице, `--rm` без
  `git reset`. Это решаемо расширением `run.sh` (добавить подкоманды `py`, `check`), без docker.
